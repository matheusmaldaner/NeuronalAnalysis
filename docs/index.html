01 / Overview

What the project asks

How the transcriptional profiles of individual neurons, characterized by their anatomical and functional properties, can be used to model and predict neuronal network behavior in a neurosymbolic framework.

The analysis runs on a Mus musculus single-cell RNA-seq experiment from refine.bio (SRP094496), which combines in vivo labeling, patch clamp recordings, and single-cell RNA-seq so that each neuron carries both an expression profile and measured anatomical and functional properties.

Samples were split into two classes based on their recorded cell type, and the pipeline moves from gene identifier mapping and normalization through differential expression, enrichment, unsupervised clustering, and supervised classification. Every figure below comes from that pipeline, which lives in the repository as combined-file.Rmd and ensembl-to-hugo.R.

02 / Pipeline

Four stages, all in R

Implemented with Bioconductor tooling, each stage feeding the next.

01

Preprocessing

Ensembl identifiers mapped to HUGO symbols with the house mouse annotation package, log scaling, and density checks across roughly 41,000 measured variables.

02

Expression structure

PCA on a DESeq2 dataset and UMAP embedding to see how the two sample classes separate, followed by differential expression and a volcano plot of the significant genes.

03

Enrichment and clustering

Gene set enrichment with topGO, clusterProfiler, and gprofiler2, then k-means, hierarchical clustering, and ConsensusClusterPlus compared against each other with chi-squared tests and alluvial diagrams.

04

Supervised models

SVM, logistic regression, random forest, and naive Bayes trained on the most variable genes, with gene signatures extracted per model and rerun across different gene set sizes.

03 / Interactive

K-means, one iteration at a time

Stage three compares k-means against hierarchical and consensus clustering. This is that algorithm made steppable: pick a k, then alternate between assigning every point to its nearest centroid and moving each centroid to the mean of the points it captured.
